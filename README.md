# QueryAnytime

**Query Anytime: Find When Before Where for Online 4D Point Cloud Segmentation**

QueryAnytime is an online query-driven 4D point cloud segmentation framework designed for natural-language queries that may arrive at arbitrary times in a continuously evolving 3D stream.

The framework follows a **find when before where** principle:

- **Find when:** Searchable Evidence Tokenization (SET) builds a compact, query-independent evidence space for efficient temporal grounding without revisiting dense history.
- **Find where:** TrackState maintains a semantic-geometric target state for spatially continuous, instance-consistent segmentation over time.
